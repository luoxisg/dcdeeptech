01 // CDU PROCESS

CDU 冷量分配单元 — 博士级工艺深度解析

CDU 是液冷系统的"神经中枢"，其设计不止于泵与换热器的堆叠，更涉及流体力学控制论、材料电化学、气液热力学平衡等跨学科研究领域。以下为工程博士级核心知识点。

// 01.A · FLUID MECHANICS
动态压差补偿控制（DP Control）
采用变频驱动（VFD）泵组 + 模糊 PID 算法，实时监测二次侧各支路阻力变化。当 GPU 负载突变时，CDU 响应时间需在 200ms 内完成流量重分配。
Q = ΔP / R_hyd = (P_pump - ΔP_sys) / Σ(8μL/πr⁴)
Q: 支路流量 | ΔP: 差压 | R_hyd: 液阻 | μ: 动力粘度 | r: 等效管径
每路冷板流量偏差须控制在 ±3~5% 以内，以保证多卡温度均一性。
// 01.B · ELECTROCHEMISTRY
电化学腐蚀防治
二次侧冷媒（乙二醇水溶液）对 不锈钢/铜/铝 存在不同的电化序差异，驱动点蚀与晶间腐蚀。关键控制参数：
pH: 7.0 ~ 9.0 | 导电率: <100 μS/cm | DO: <0.1 mg/L
板式换热器（BPHE）密封件需选用耐乙二醇的 EPDM，定期评估溶胀率（溶胀率 <5%）。
✔ 在 CDU 内集成在线去离子（DI）回路，抑制离子积累，防止CPU冷板铜镍层针孔腐蚀。
// 01.C · THERMODYNAMICS
气液平衡与膨胀补偿
液冷系统在 -20℃ 至 60℃ 工况下，体积变化率约 1.5~2.8%。膨胀罐容积须精确设计：
V_exp = V_sys × (e_v / (1 - P₀/P_max))
e_v: 体膨胀系数 | P₀: 初始气压 | P_max: 系统最高压
气垫型膨胀罐须预充 0.5~0.8 bar 氮气，防止泵入口 NPSH 空化（汽蚀）。
⚠ 空化会产生瞬时气泡，导致管路振动噪音与叶轮腐蚀侵蚀。
// 01.D · HEAT TRANSFER
板换设计与 LMTD 分析
CDU 一次侧（楼宇冷冻水）与二次侧（IT 冷水）通过 BPHE 换热，对数平均温差 LMTD 是核心设计参数：
Q = U × A × LMTD = U × A × (ΔT₁ - ΔT₂) / ln(ΔT₁/ΔT₂)
典型参数：二次侧进水 25~40°C、出水 45~55°C；一次侧进水 15~20°C。U 值目标 ≥5000 W/(m²·K)。
// 01.E · REDUNDANCY
N+1 泵冗余与控制切换
生产级 CDU 必须具备：
• 双泵 N+1 并联，切换时间 <100ms
• 泵控 PLC 支持在线热替换（Hot-Swap）
• 电源 双路冗余输入（UPS +市电）
• 传感器冗余：双路压力 + 双路流量
✔ 推荐屏蔽式磁力泵，无动密封泄漏风险，MTBF >60,000 小时。
// 01.F · CONTROLS & DIGITAL TWIN
数字孪生与能效预测
在 CDU 上部署 ≥20 路传感器（温度/压力/流量/电导率/溶解氧），构建实时数字孪生模型：
• GPU 热功耗预测误差 <±2%
• 自适应 VFD 转速优化，节电 15~25%
• 预测性维护：轴承振动分析提前 30 天预警
建议采用 MQTT 协议接入 DCIM 平台，打通机房整体能效优化闭环。

02 // COLD PLATE TECHNOLOGY

液冷冷板 — 微通道拓扑、材料选型与制造工艺

微通道热力学模型

// NUSSELT NUMBER · 层流
微通道强制对流传热（Dh <1mm）
Nu = h·Dh/λ = 0.023·Re⁰·⁸·Pr⁰·⁴ (Dittus-Boelter, Re>10000) Dh=(4A/P): 水力直径 | λ: 导热系数 | Pr: 普朗特数
微通道当量直径 0.2~1.0 mm 时属过渡/层流区，需用 Shah & London 关联式修正。Re > 10,000 可触发湍流，传热系数可达 15,000~50,000 W/(m²·K)。
// PRESSURE DROP · Darcy-Weisbach
压降设计优化
ΔP = f·(L/Dh)·(ρv²/2) + K_local·(ρv²/2)
GPU 冷板压降目标 <15 kPa（单板）。增加通道数可降流速但降 h，存在最优点：Dh=0.5~0.8mm、通道间距=0.3~0.6mm 常为黄金比例。
✔ 拓扑优化（SIMP法）或仿生叶脉结构可在不增加压降的前提下提升 Nu 15~30%。

// SURFACE TREATMENT
铜冷板表面处理体系
化学镀镍磷（Electroless Ni-P）：厚度 5~10μm，硬度 HV 500~700，抗腐蚀性优异，为 AI 冷板主流处理方案。
无铅 ENIG 金：接触面接触电阻最低，用于 TIM 界面。
⚠ 铜铝直接接触须防止电偶腐蚀，必须加绝缘隔离层或 Ni 缓冲层。

冷板核心制造工艺对比（博士级工艺路线图）

// PROCESS A · CNC + 真空钎焊
CNC 铣削 + 高温真空钎焊
主流工艺铜冷板首选
CNC 五轴铣削微通道（表面粗糙度 Ra ≤0.8μm），银铜钎料（BAg-7，熔点 780°C）在 真空炉（10⁻⁴ Pa）中 820°C 钎焊。

优势：密封可靠性高，适合复杂流道；劣势：能耗高、批次小、节拍慢（4~8h/批）。
✔ 适合 AVC/CoolerMaster CPU/GPU 冷板小批量高精度需求
// PROCESS B · FSW 搅拌摩擦焊
搅拌摩擦焊 (FSW)
铝板首选AI 大规模量产
固态焊接，焊接温度约 400~550°C（铝），远低于熔点。焊缝组织细密，无气孔，接头强度达母材 85~100%。

优势：节拍快（≤30s/米）、自动化程度高、良率 >99%；劣势：不适合壁厚 <1.5mm 的薄板。
焊接速度: 300~1500 mm/min | 转速: 800~3000 rpm | 轴向力: 5~15 kN
// PROCESS C · 扩散焊 / 液相扩散焊
扩散焊（TLP）/ 瞬时液相焊
高端应用铜铝异种金属
在 高温高压（铜：800°C / 10~30 MPa）下通过原子扩散实现冶金连接，无钎料，无成分突变，热阻极低。

适用于 5G 基站、EV 电池高可靠冷板。成本约为钎焊的 2~3倍，产能受限于热压机台数。
✔ 接头热阻可达 0.01 cm²·K/W，为钎焊接头的 1/5。
// PROCESS D · 机加+环氧密封
机械加工 + 螺栓锁紧 + 密封圈
低成本快速样品
CNC 铣削上下盖板，O-Ring（EPDM/Viton）密封，螺栓压紧。

优势：无焊接设备，交期最短（3~5天 NPI）；劣势：高压泄漏风险，长期可靠性受密封件老化影响，不建议量产。
⚠ 仅适合 PoC 样品验证，严禁用于数据中心生产环境。
// PROCESS E · 微铸造 / 3D打印
金属 3D 打印（SLM/DMLS）
拓扑优化/科研
激光粉末床熔融（L-PBF）可实现任意复杂内流道，无传统加工限制。材料：316L 不锈钢、铜（GRCop-84）、铝 AlSi10Mg。

分辨率约 80~120μm，表面粗糙度 Ra 10~30μm（需后处理）。成本是 CNC 的 5~20倍，适合极端拓扑研究。
// PROCESS F · 电铸成形
电化学沉积（电铸）
超精密微通道
通过芯模电铸铜/镍，可实现 50~200μm 级超细微通道，Ra <0.1μm。热通量可超越传统机加 3~5倍。

适用场景：激光二极管冷却、高功率功放模块。量产节拍受限于电镀速率，成本极高。

TIM 接口层热阻分析

LAYER 1
芯片 Die ↔ IHS 键合层
英特尔/AMD 采用液态金属（InGaSnBi），热阻 0.002~0.005 °C·cm²/W；NVIDIA GPU 使用钎料焊接（低熔点 Sn-In 合金），热阻 0.003~0.008。
LAYER 2
IHS 顶面 ↔ 冷板底面（TIM2）
导热垫（Phase Change TIM）：热导率 12~25 W/(m·K)，推荐 Henkel Bergquist GP2000 或 Laird T-flex 系列。厚度控制 50~150μm，总热阻目标 <0.02 °C·cm²/W。
LAYER 3
冷板底板 ↔ 微通道壁面
金属导热，铜冷板导热热阻可忽略（<0.001）。主要热阻来源在微通道对流 Rcv = 1/(h·A_fin)。Fin 效率 η 须 >85%。
TOTAL
系统总结热阻（Die→冷水）
优化设计目标：R_total < 0.05 °C·cm²/W（高端液冷冷板）。对应 400W GPU Die，结点温度 Tj ≈ Tin + 400W × 0.05/A_die。

机架级液冷管路集成设计要点

// MANIFOLD DESIGN
歧管均流设计
采用 对称/渐缩型歧管，利用 CFD（Fluent/OpenFOAM）验证各支路流量均匀性（CV <5%）。歧管材质：挤压铝（氧化处理）或不锈钢 316L，内径≥16mm 以降低系统压降。
✔ OCP 标准采用 ⌀12 进出水管+Stäubli RBE 快插，支持带压插拔（Hot-Swap）。
// QUICK CONNECT
无滴漏快插接头
Stäubli SPH/RPB 系列：插拔力 <30N，密封压力 >10 bar，泄漏率 <0.001 mL/min，寿命 >1000 次插拔。
Colder PLC：成本较低，单向阀设计，带压 0.5 bar 可插拔，适合大批量 OEM。
⚠ 严禁混用不同品牌公母接头，密封面尺寸偏差将导致泄漏。
// LEAK DETECTION
泄漏检测与封堵
在线：机架底部铺设离子感应泄漏绳（200mm间距），响应时间 <5s，精确定位至 50cm。
出厂：整机氦气检漏（He Mass Spectrometer），泄漏率标准 <1×10⁻⁶ Pa·m³/s。
✔ 建议在 CDU 回水管路加装 0.1mL 精度流量差分计，远程监控泄漏趋势。

OEM 合作流程 — 从需求到量产

PHASE 1 · 2~4 WEEKS
需求对接与规格书锁定（TDS/SRS）
提供：GPU/CPU 热设计功耗（TDP W）、Die 尺寸、安装孔位图（STEP 3D 文件）、冷水进出水温、最大允许压降、接口规格（OCP/自定义）、MTBF 要求。AVC/CM 反馈初步可行性分析及报价。
PHASE 2 · 3~5 WEEKS
仿真验证（CFD + FEA）
OEM 方使用 ANSYS Fluent 或 FloTHERM 进行冷板流道热仿真，确认：最大 Tj、热阻 R_total、压降 ΔP、流量 Q。结构 FEA 验证高压（3 bar）下冷板变形量 <20μm（TIM 压缩控制）。
PHASE 3 · EVT · 4~6 WEEKS
工程验证样品（EVT）制作与测试
首批 5~10 片样品，进行：热阻测试（热阻仪+Microfocus X-Ray 检查钎焊空洞）、氦气泄漏测试（<1×10⁻⁶ Pa·m³/s）、水压测试（1.5×MAWP, 30min 保压）、热冲击（-40~85°C 200 cycles）。
PHASE 4 · DVT · 3~4 WEEKS
设计验证（DVT）与可靠性测试
30 片 DVT 批次，覆盖：HALT 高加速寿命（振动+温度复合）、HAST 高压蒸汽老化、插拔寿命（1000 次快插接头）、长时运行（7×24h 满载热浸泡）。AVC/CM 出具测试报告，锁定制程工艺。
PHASE 5 · MP · 量产爬坡
量产（MP）上线与 PPAP 文件包
提交完整 PPAP Level 3 文件包（控制计划/PFMEA/MSA/Cpk 分析），产线良率目标 >99.5%，建立 SPC 管控 CNC 关键尺寸（通道深度 Cpk >1.67），ATE 在线测试全检（气密+热阻+外观 AI 视觉）。
