🏗️ Open Rack v3 (ORv3)

The OCP standard rack form factor for high-density AI. 21" wide, accommodates DC power and liquid cooling manifolds at the rear.面向高密度 AI 的 OCP 标准机柜规格，21 英寸宽，后部集成直流供电与液冷歧管。

  • 21" wide rack vs 19" legacy
  • 48V DC native power bus
  • Rear liquid cooling manifold ready
  • Open Rack Bus Bar (ORBB) compatible
  • Up to 60 kW/rack power budget
💧 Direct Liquid Cooling (DLC)

Server-level liquid cooling for >400W GPU TDP. Works with rear-door heat exchangers (RDHx) or direct-to-chip (D2C) coldplate loops.面向 >400W GPU TDP 的服务器级液冷，兼容后门换热器 (RDHx) 或直接芯片冷板回路 (D2C)。

  • CDU (Coolant Distribution Unit) design
  • 35°C inlet water temperature target
  • Manifold pressure ≤2.0 bar operating
  • Compatible with H100/H800/B200 coldplates
  • PUE improvement: 1.6→1.15 typical
⚡ OCP Power Architecture

OCP favors 48V DC distribution (HVDC) to eliminate intermediate AC/DC conversion losses and support Battery Backup Units (BBU) at rack level.OCP 推广 48V 直流配电 (HVDC)，消除中间 AC/DC 转换损耗，支持机架级电池备用单元 (BBU)。

  • 48V HVDC vs 12V legacy loss reduction
  • Open Rack PSU (ORPS) form factor
  • Rack-level BBU replaces UPS rooms
  • Dual-bus redundancy (A+B feeds)
  • Power Cap API via OpenBMC/Redfish
🖥️ OpenBMC + Redfish

OCP mandates open management firmware. OpenBMC replaces vendor-locked IPMI implementations and exposes hardware via Redfish REST API.OCP 要求开放管理固件。OpenBMC 替换供应商锁定的 IPMI，通过 Redfish REST API 暴露硬件接口。

  • OpenBMC firmware (Meta/Linux Foundation)
  • Redfish v1.x REST API for all CRUD ops
  • OOB management over dedicated NIC
  • Telemetry: thermal, power, health metrics
  • OCP OSIE (OS Install Environment)

from openai import OpenAI

client = OpenAI(
    base_url="https://api.dcdeeptech.io/v1",
    api_key="dct-your-key-here",

# List available models
models = client.models.list()
for m in models.data:
    print(m.id, m.pricing)

# Chat completion
response = client.chat.completions.create(
    model="qwen/qwen2.5-72b-instruct",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},

    stream=True,               # SSE streaming supported
)
for chunk in response:
    print(chunk.choices[0].delta.content, end="")
