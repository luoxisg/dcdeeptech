# China Outbound Enterprise Lead Intelligence Platform

## Purpose

This MVP turns public market signals into qualified target-company lists, evidence-backed match reasons, likely service needs, recommended buyer roles, opening angles, and CRM-ready exports.

## Core agents

- Agent A: USD-Funding / VIE Lead Agent
- Agent B: Digital Globalization Lead Agent
- Agent C: Heavy-Asset Global Expansion Lead Agent

## v1 boundaries

- Included: search, scoring, detail evidence, watchlist, export, seeded fixtures
- Excluded: auto-email, autonomous outreach, full CRM sync
