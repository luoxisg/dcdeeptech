# DCDeepTech USD Lead Discovery Platform

This folder now contains a standalone v1 prototype for the B2B lead discovery agent platform.

## Files

- `index.html`: Single-file product prototype with:
  - Candidate discovery
  - Company normalization
  - Funding signal analysis
  - Lead scoring
  - CRM-ready lead card generation

## Notes

- This prototype focuses on qualification and exportable lead intelligence.
- Auto-email sending is intentionally excluded from v1.
- A fuller app/service implementation also exists under `platform-sg/`.
